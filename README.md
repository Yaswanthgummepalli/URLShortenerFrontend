# URL Shortener

A full-stack URL Shortener application built using React and Spring Boot.

## Features

- Generate short URLs
- Prevent duplicate URLs
- Trim whitespace before saving
- REST APIs
- Responsive UI

## Tech Stack

Frontend
- React
- CSS
- Fetch API

Backend
- Spring Boot
- Spring Data JPA
- MySQL

## Setup

### Frontend

Create a `.env` file:

VITE_API_URL=your backend url

Run:

npm install
npm run dev

### Backend

Run the Spring Boot application.
